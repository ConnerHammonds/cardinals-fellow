# README

Includes answers and source code for cardinals assessment. Some csv's have not been included for the sake of size. All graphics and models should be reproducible.

## Project layout

| Folder | Contents |
|---|---|
| `src/` | Contains source code for baserunner model and McGreevy heatmaps |
| `images/` | Contains heatmaps from `pitch_location_analysis.ipynb` |
| `pulls/` | Contains the scripts that pull necessary statcast data |

CSV's have been kept in project directory to make file pathing for the scripts easy.

**Note:** Claude was used for help with syntax for libraries (pandas, numpy, scikit) since I don't have the function signatures memorized for all of those libraries. Ideas are my own.
